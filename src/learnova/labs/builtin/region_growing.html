Region Growing, step by step

Pixels are grouped into larger regions based on a condition. We start from one seed pixel, look at its neighbours one by one, and accept a neighbour only if the region still satisfies the condition after adding it. Condition from your notes:

max[P(x,y)] − min[P(x,y)] ≤ T   (T = 3)

Algorithm (from your notes)

  1. Pick up a pixel as the seed pixel.
  2. Examine its nearest neighbours one by one (4-, D- or 8-connectivity).
  3. Accept a neighbouring pixel if it satisfies the condition.
  4. Examine the neighbours of this new pixel.
  5. Continue till no new pixel is accepted.
  6. Give a unique label to the current region.
  7. Select a new seed pixel and continue the procedure.
  8. Do this until all pixels are assigned to some region.

Step log

Example 1 worked out

  1. Seed: pixel (2,3) = 6. Region = {6}, min = max = 6.
  2. First neighbours: 6, 6, 6, 7 are checked. Adding 7 makes max = 7, min = 6, difference 1 ≤ 3, so it is accepted.
  3. A 4 appears: max 7 − min 4 = 3 ≤ 3, so it is accepted. Now the window is exactly [4, 7].
  4. A 3 appears: 7 − 3 = 4 > 3, so it is rejected. Every 0–3 pixel is rejected the same way.
  5. Stop: no new pixel can be accepted, so this is R1 = all connected pixels with values 4–7 (36 pixels).
  6. New seed: (5,5) = 3. It grows through 2, 3, 0, 1 with range [0, 3] and becomes R2 (28 pixels). All 64 pixels are now assigned.

What changes the answer

  • Threshold T: smaller T means a stricter condition. With T = 2 the first region keeps only values 5–7, and the 4s go to other regions. Larger T gives fewer, bigger regions.
  • Seed pixel: the region depends on where you start. Seed 3 first (Example 3) takes values 2–5, which is a different split from Example 1.
  • Order of checking: the range is updated after every accepted pixel, so what gets accepted early decides the window for later pixels.
  • Connectivity: with 4-connectivity, pixels touching only at a corner are not neighbours, so regions can break apart.

Exam points

  • Region growing is a similarity-based (region-based) segmentation method.
  • Pros: connected regions, simple, works on noisy edges.
  • Cons: depends on the seed and threshold choice; computationally slow.
