CYK parsing, cell by cell

The CYK algorithm decides whether a context-free grammar in Chomsky normal form can generate a sentence. It fills a triangular chart from single words up to the whole sentence, trying every split point.

cell(i,j) ∋ A if A → B C, B ∈ cell(i,k), C ∈ cell(k+1,j)

Key ideas

  • Fill by span length: 1 word, then 2, … up to n.
  • For each cell try every split point k between i and j.
  • A rule A → B C fires when B covers the left part and C the right part.
  • Accept if S is in the top cell; ambiguity shows up as several ways to build the same symbol.
