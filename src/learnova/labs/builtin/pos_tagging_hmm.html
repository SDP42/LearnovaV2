Part-of-speech tagging with an HMM

An HMM tagger learns transition probabilities (tag → next tag) and emission probabilities (tag → word) from a tagged corpus, then uses Viterbi to find the best tag sequence for a new sentence.

t̂ = argmax_t Π P(t_i | t_{i-1}) · P(w_i | t_i)

Key ideas

  • Transition a(t→u) = count(t u) / count(t), including from the start <s>.
  • Emission b(t, w) = count(w tagged t) / count(t).
  • The same word can carry different tags (will/M vs Will/N); the context decides.
  • Viterbi over tags gives the most likely tag sequence.
