Viterbi decoding, step by step

A hidden Markov model has hidden states that emit visible observations. Viterbi finds the single most likely state sequence by keeping only the best path into each state at each time.

v_t(s) = max_r v_{t-1}(r) · a(r→s) · b(s, o_t)

Key ideas

  • One column per observation, one row per state.
  • Each cell keeps only the best incoming path (max, not sum — that would be the forward algorithm).
  • Remember the backpointer: which previous state gave the max.
  • Trace back from the best final cell to read the sequence.
